# This is requirements.txt MINUS rembg. Why:
#   rembg[cpu] pulls in onnxruntime and downloads a ~176MB AI model on
#   first use. Render's free tier gives the service 512MB of RAM, so
#   loading that model would crash the server. rembg only powers the
#   LOCAL background-removal fallback - on the deployed app, the real
#   photo enhancement is done by OpenAI/Gemini instead, and the code
#   already handles rembg being absent (it imports it lazily and reports
#   "background removal unavailable" honestly rather than crashing).
#
# Keep this file in sync with requirements.txt when adding packages.
# Local development still uses requirements.txt and keeps rembg.
